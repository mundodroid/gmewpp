Privacy Policy - Mundo Droid Poster

Last updated: November 11, 2026

Mundo Droid Poster ("the app", also shown as "AutoPost AI Pro") is a Windows desktop application that lets a creator schedule and publish their own short videos to their own TikTok, Instagram and YouTube accounts using only the official APIs of each platform.

1. Data we access

  • TikTok: basic profile (open ID, display name, avatar) via user.info.basic, used only to show which account is connected; creator posting information (allowed privacy levels, maximum video duration, interaction settings) via the Content Posting API, used only to validate a post before it is sent.
  • Instagram (Meta): the professional account ID, username, name and profile picture, used only to show which account is connected; publishing limits and the status of media containers, used only to publish and confirm the user's Reels.
  • YouTube (Google): via the youtube.upload and youtube.readonly scopes, the channel ID, title and thumbnail (to show which channel is connected), the upload and processing status of videos sent by the app, and view counts of those videos (to suggest posting times to the user).
  • Videos and captions selected by the user on their own computer, which are uploaded to the platforms only when the user schedules or publishes them.

2. Where data is stored

All data stays on the user's own computer. Access tokens are encrypted (AES/Fernet) and the encryption key is kept in the Windows Credential Manager. The app does not operate a server that collects user data, and it never asks for or stores passwords of TikTok, Instagram, Facebook or Google accounts.

For Instagram only, the platform requires the video to be available at a public link: the app uploads the video to the user's own storage bucket (configured by the user, for example Cloudflare R2), creates a temporary signed link and deletes the file after the post is published.

3. How data is used

Data is used exclusively to publish the videos the user chooses, at the time the user chooses, and to show the publishing status and simple statistics to the user. Data is not sold, shared with third parties, or used for advertising.

4. Google API Services

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained from YouTube is used only to provide the publishing features described above and is never transferred to others, used for advertising, or read by humans.

5. Third-party services

Videos are sent directly from the user's computer to the platforms. If the user enables AI-generated captions, frames of the video and its audio transcription may be sent to the AI providers configured by the user (Anthropic and, for audio transcription, an OpenAI-compatible service) to generate a title and hashtags. No data obtained from TikTok, Instagram or YouTube APIs is sent to these AI providers.

6. Retention and deletion

The user can disconnect any account at any time inside the app, which deletes the stored tokens and revokes the access where the platform allows it. Uninstalling the app and deleting its data folder removes all local data. Access can also be revoked directly on each platform:

  • TikTok: Settings > Security > Manage app permissions.
  • Instagram / Meta: Settings > Apps and websites, or Business settings > Apps.
  • Google / YouTube: myaccount.google.com/permissions.
