Privacy Policy - Mundo Droid Poster

Last updated: November 11, 2026

Mundo Droid Poster ("the app") is a Windows desktop application that lets a creator schedule and publish their own short videos to their own TikTok account using the official TikTok Login Kit and Content Posting API.

1. Data we access

  • TikTok basic profile (open ID, display name, avatar) via the user.info.basic scope, used only to show which account is connected.
  • Creator posting information (allowed privacy levels, maximum video duration, interaction settings) via the Content Posting API, used only to validate a post before it is sent.
  • Videos and captions selected by the user on their own computer, which are uploaded to TikTok only when the user schedules or publishes them.

2. Where data is stored

All data stays on the user's own computer. Access tokens are encrypted (AES/Fernet) and the encryption key is kept in the Windows Credential Manager. The app does not operate a server that collects user data, and it never asks for or stores TikTok passwords.

3. How data is used

Data is used exclusively to publish the videos the user chooses, at the time the user chooses, and to show the publishing status. Data is not sold, shared with third parties, or used for advertising.

4. Third-party services

Videos are sent directly from the user's computer to TikTok. If the user enables AI-generated captions, video metadata may be sent to the AI provider configured by the user (Anthropic) to generate a title and hashtags.

5. Retention and deletion

The user can disconnect the TikTok account at any time inside the app, which deletes the stored tokens and revokes the access. Uninstalling the app and deleting its data folder removes all local data. Access can also be revoked at any time in the TikTok app under Settings > Security > Manage app permissions.
